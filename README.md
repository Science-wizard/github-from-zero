# 🚀 GitHub From Zero

### From your first commit to your first collaborative software project.

Welcome to **GitHub From Zero**, a beginner-friendly, hands-on learning project designed to help students and aspiring developers understand Git, GitHub, and collaborative software development.

Have you ever opened GitHub and wondered what repositories, branches, commits, pull requests, and merge conflicts actually mean?

Have you ever wanted to participate in a hackathon but felt intimidated by the way developers collaborate?

You're in the right place.

This project takes you from absolute beginner to confidently contributing to collaborative software projects.

**No previous Git or GitHub experience required.**

---

## 🎯 Our Mission

Our mission is to make collaborative software development accessible to everyone.

We believe that learning Git and GitHub shouldn't involve blindly memorising commands. Instead, learners should understand the engineering concepts behind version control and experience them through practical exercises.

We want every beginner to be able to:

- Create and manage GitHub repositories.
- Work with Git from their local machine.
- Understand branches and version control.
- Collaborate with other developers.
- Submit and review pull requests.
- Resolve merge conflicts.
- Participate confidently in hackathons and open-source projects.

---

This project is particularly useful for:

## 🗺️ Learning Roadmap

Our learning journey is divided into progressive modules.

### 01. Getting Started

Understand the fundamentals before writing your first Git command.

- What is Git?
- What is GitHub?
- Git vs GitHub.
- What is version control?
- Understanding repositories.
- Creating your first GitHub repository.

### 02. Git Fundamentals

Learn how Git manages changes in your project.

- Installing and configuring Git.
- Cloning repositories.
- Understanding local and remote repositories.
- Git status.
- Working directory and staging area.
- Git add.
- Git commit.
- Git push.
- Git pull.
- Git fetch.

### 03. Branching

Learn how developers work independently on the same project.

- What are branches?
- Understanding the main branch.
- Creating branches.
- Switching between branches.
- Naming conventions.
- Deleting branches.
- Keeping branches synchronised.

### 04. Collaboration

Learn how multiple developers contribute to one repository.

- Inviting collaborators.
- Cloning shared repositories.
- Creating feature branches.
- Submitting pull requests.
- Reviewing code.
- Requesting changes.
- Approving pull requests.
- Merging contributions.

### 05. Advanced Git

Understand common problems and more advanced workflows.

- Understanding merge conflicts.
- Resolving merge conflicts.
- Git stash.
- Git reset.
- Git revert.
- Git rebase.
- Understanding Git history.

### 06. Real-World Hackathon Workflow

Put everything together in a simulated engineering team.

- Organising a development team.
- Assigning responsibilities.
- Creating feature branches.
- Managing parallel development.
- Reviewing teammates' contributions.
- Synchronising repositories.
- Resolving conflicts.
- Preparing the final submission.

## 🧠 Our Teaching Philosophy

Every concept in this repository follows five principles:

1. **Understand:** Learn what the concept means.
2. **Why:** Understand the engineering problem it solves.
3. **Visualise:** Use diagrams and examples to build intuition.
4. **Practice:** Execute commands on your own machine.
5. **Challenge:** Complete an exercise independently.

We don't want you to memorise commands.

We want you to understand what happens behind them.

Open it in Visual Studio Code:

```bash
code .
```
